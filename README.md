# ATM Banking System in C

## Overview
This project is a console-based ATM Banking System developed using the C programming language.  
It simulates basic ATM functionalities with a simple and user-friendly menu-driven interface.


## Features
- PIN-based user authentication  
- Check account balance  
- Deposit money  
- Withdraw money  
- Menu-driven console interface  

## Technologies Used
- C Programming Language

## Project Details
- Initial balance is predefined for demonstration purposes  
- PIN is validated before allowing access to ATM operations  
- Designed to strengthen understanding of C fundamentals  

## How to Run the Project
1. Open the project in any C compiler (GCC recommended)
2. Compile the source file  
gcc atm.c -o atm

3. Run the executable file  
./atm

4. Enter the correct PIN to access the ATM menu
